# Project: **SokoHub** — Multi-Vendor E-Commerce Marketplace (Kenya-First)

A production-grade, multi-vendor marketplace platform targeting the East African market, with **M-Pesa STK Push as a first-class payment citizen** alongside card payments, featuring everything a modern e-commerce platform needs to be taken seriously at scale.

---

## Why This Stands Out

The Kenyan/EA angle is your **unfair advantage** as a portfolio piece. Most e-commerce demos use Stripe in USD. You're building something that:

- Handles **M-Pesa STK Push via Safaricom Daraja API 3.0** with proper idempotency — because Safaricom can send the same callback more than once, and double-processing an order is a production bug https://www.questdesigners.com/blog/mpesa-integration-to-website
- Models **multi-vendor payouts** (B2C back to vendor M-Pesa wallets)
- Handles **KES + USD** currency toggling
- Is still globally architected enough to impress any international recruiter

## M-Pesa Integration Specifics

The STK Push flow is non-trivial and shows real Daraja API knowledge https://github.com/Jcardif/MpesaDaraja https://www.questdesigners.com/blog/mpesa-integration-to-website:

| Step | What Happens |
|---|---|
| Checkout initiated | Frontend POSTs phone number + amount to API |
| STK Push triggered | Backend calls Daraja `MpesaExpress.InitiateStkPush` with `CheckoutRequestID` stored to Redis with TTL |
| Customer prompted | Safaricom sends PIN prompt to customer's phone |
| Callback received | Daraja POSTs to `/api/payments/mpesa/callback` — idempotency check on `MpesaReceiptNumber` against MSSQL before processing https://www.questdesigners.com/blog/mpesa-integration-to-website |
| Order confirmed | Payment service publishes event to RabbitMQ → Order service consumes → triggers email/SMS via Notification service |
| Vendor payout | B2C flow sends vendor's commission share to their M-Pesa number |

## Technology Justification (Nothing Shoehorned)

| Tech | Exact Justification |
|---|---|
| **MSSQL** | Orders, users, vendors, products — core relational data |
| **PostgreSQL** | Analytics/reporting read store, separate from write MSSQL |
| **MySQL** | Promotions/coupon engine (isolated bounded context) |
| **MongoDB** | Audit trail, payment event documents, Daraja callback raw payloads |
| **Redis** | Cart sessions, STK Push pending checkout TTL, rate limit counters, product search cache |
| **Oracle** | Financial ledger (vendor commissions, platform fees) — enterprise-grade finance data |
| **RabbitMQ** | Internal domain events: order confirmed → trigger email, trigger inventory deduct |
| **Kafka** | Payment event streaming, audit log pipeline, analytics ingestion |
| **JWT** | Auth across all services, role-based claims |
| **Rate Limiting** | Checkout endpoint, STK Push (Safaricom limits calls), login brute-force |
| **Docker + K8s** | Every service containerized, Helm charts for deploy |
| **Terraform** | AKS/EKS infra provisioning, managed DB instances |
| **GitHub Actions** | CI per module, CD to staging on PR merge, production on release tag |

## docker-compose.yml Services (Outline)

```
services:
  api                ← .NET 10 Web API
  frontend           ← Nuxt.js SSR
  mssql              ← Orders, users, products (primary)
  postgres           ← Analytics/reporting
  mysql              ← Promotions engine
  mongo              ← Audit log + Daraja raw payloads
  redis              ← Cart, STK TTL, search cache, rate limits
  oracle-xe          ← Financial ledger (Oracle XE for local dev)
  rabbitmq           ← Domain event bus
  kafka              ← Payment + audit streaming
  zookeeper          ← Kafka dependency
  mailhog            ← Local email inbox (order confirmations)
  seq                ← Structured log viewer (dev)
  adminer            ← Multi-DB GUI (dev)
  ngrok              ← Daraja callback tunnel (local dev only)
```

> **ngrok** in compose is intentional and impressive — it shows you understand that Daraja's STK callback requires a **publicly reachable URL**, so local dev needs a tunnel. Recruiters who know Daraja will notice this immediately.
